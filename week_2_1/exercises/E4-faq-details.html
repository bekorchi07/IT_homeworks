Frequently Asked Questions

What does semantic HTML mean?

Semantic HTML means choosing elements based on their meaning and purpose, not their appearance. It helps search engines, screen readers, and other tools understand the structure and content of your page.

What is the difference between block and inline elements?

Block elements take up the full width available and start on a new line, like div, p, and section. Inline elements only take up as much width as necessary and flow within text, like span, a, and em.

When should I use <article> vs <section>?

Use <article> for self-contained, syndicate-able content like blog posts or news articles. Use <section> for thematic grouping of content within a page.

What is ARIA and why is it important?

ARIA is a set of attributes that help make web content more accessible to people with disabilities. It provides additional context to assistive technologies about dynamic content and user interface controls.
